# Modul CSS Praktikum

Praktikum CSS dari Modul Web 3 - Cascading Style Sheet.

## Daftar Latihan

| File | Topik |
|------|-------|
| `a-background.html` | CSS Background (color, image, gradient) |
| `b-dimension.html` | CSS Dimension (width, height, margin, padding) |
| `c-text.html` | CSS Text (color, spacing, transform, font) |
| `d-border.html` | CSS Border (style, width, color, radius) |
| `e-position.html` | CSS Position (static, relative, absolute, fixed, sticky) |
| `f-navigation.html` | Navigation Bar (horizontal & vertical) |
| `g-multiple-column.html` | Multiple Column Layout |
| `h-image-gallery.html` | Image Gallery |
| `i-media-query.html` | Media Query (responsive background) |
| `j-grid.html` | Grid System (12-column layout) |
| `k-responsive-article.html` | Responsive Article |
| `l-responsive-gallery.html` | Responsive Image Gallery |
| `m-responsive-template.html` | Responsive Template (header, sidebar, content, footer) |
| `n-responsive-form.html` | Responsive Form |

## Cara Membuka

1. Buka folder `modul-css-praktikum` di file explorer
2. Double-click file HTML yang ingin dilihat
3. Atau drag-drop file ke browser

## Gambar Placeholder

Folder `images/` berisi gambar placeholder. Ganti dengan gambar asli sesuai kebutuhan:
- `batako.jpg` - untuk background texture
- `logo.png` - logo untuk background position
- `logo_white.png` / `logo_putih.png` - logo untuk header
- `soeharto.jpg`, `habibi.jpg`, `gusdur.jpg`, `sby.jpg`, `jokowi.jpg` - foto presiden

## Tested On

- Browser: Chrome, Firefox, Edge
- Responsif: Desktop (>768px), Tablet (600-768px), Mobile (<600px)
